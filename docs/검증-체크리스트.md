# 검증 체크리스트 — 실제 브라우저에서 손으로

> **왜 필요한가:** 지금까지 만든 것은 자동화 테스트 341개와 스크린샷으로만 검증됐다.
> jsdom 은 "선이 실제로 원하는 핀에서 나오는가", "20가닥일 때 레인이 정말 안 겹치는가",
> "인쇄물이 읽히는가"를 답하지 못한다. **특히 PDF 는 아무도 열어본 적이 없다.**
>
> 이 목록을 다 돌리는 게 목적이 아니다. **A 코스(한 바퀴)만 돌려도 대부분 드러난다.**
> 막히는 지점을 기록해 두면 그게 다음 작업의 근거가 된다.

**대상** https://qpwo5470.github.io/harness-tool/
**권장 환경** Chrome, 1440×900 이상. 첫 실행 시 샘플 하네스가 열린다.

---

## A 코스 — 실제 하네스 하나를 끝까지 (30~40분)

**실제로 만들 하네스 하나를 골라라.** 샘플을 만지지 말고 새로 만들어야
빈 상태부터 PDF 까지 전 경로가 드러난다.

### A-1. 시작

- [ ] `새 문서` → 빈 캔버스 온보딩이 뜨는가
- [ ] 상단바 `도번` `Rev` 에 실제 값을 입력 → **도면 우하단 제목블록에 그대로 나오는가**
- [ ] 문서명 변경 → 제목블록 반영

### A-2. 커넥터 배치 ⚠️ 미검증

- [ ] 라이브러리 부품을 **캔버스로 끌어다 놓기** → 놓은 자리에 생기는가
      (커서가 부품 가운데 오는가, 엉뚱한 데 생기지 않는가)
- [ ] 드래그 중 캔버스에 점선 테두리 표시가 뜨는가
- [ ] 클릭 배치도 여전히 되는가
- [ ] `+ 장치 블록` 도 드래그되는가
- [ ] 터미널(연호 터미널 그룹)은 드래그가 **안 되는** 게 맞다

### A-3. 결선 ⚠️ 미검증 — 가장 중요

- [ ] 핀에서 핀으로 **드래그해 배선이 생기는가**
- [ ] 선이 **정확히 그 핀에서** 나오는가 (도형 중간이나 옆구리에서 나오지 않는가)
- [ ] 커넥터 방향을 0/90/180/270° 로 바꿔가며 결선 → 선이 매번 맞는 변에서 나오는가
- [ ] 스플라이스에 3가닥 이상 물리기 → 네트가 하나로 이어지는가
- [ ] 규격 커넥터(RJ45 T568B)에 결선 → 규격 색이 자동 제안되는가

### A-4. 값 채우기

- [ ] 배선 클릭 → 속성 탭에서 색 칩으로 색 지정
- [ ] 규격 외 색을 **직접 입력**으로 넣기 (현장에서 쓰는 색)
- [ ] 게이지·길이 입력, AWG ↔ mm² 전환 시 값이 환산되는가
- [ ] 커넥터 클릭 → **핀 패드 격자에서 여러 핀 골라 터미널 일괄 지정**
      (핀이 많은 커넥터로 해볼 것 — 이게 리디자인의 핵심이다)
- [ ] 장치 단자 추가·이름 변경 → 이미 배선된 단자는 삭제가 막히는가

### A-5. 확인

- [ ] 접속표 탭 — 행에 마우스 올리면 도면에서 그 배선이 강조되는가
- [ ] 도면 배선에 마우스 올리면 커서 옆에 상세 카드 + 표 행 강조
- [ ] **검증 탭** — 지적 내용이 실제로 맞는가, 설명이 이해되는가
- [ ] 검증 항목 클릭 → 그 요소가 선택되고 속성 탭으로 넘어가는가
- [ ] 파트 탭 — 수량이 실제 필요 수량과 맞는가

### A-6. 출력 ⚠️ 최우선 미검증

- [ ] `PDF 도면` → 파일이 받아지는가
- [ ] **PDF 를 열어라.** 3면(배선도·접속표·파트리스트)이 나오는가
- [ ] **한글이 깨지지 않는가** (Canvas 래스터 경로를 탄다)
- [ ] 제목블록에 도번·Rev·SCALE 이 나오는가
- [ ] 도면이 페이지에 다 들어가는가, 잘리지 않는가
- [ ] **인쇄해 보라.** 핀 번호·색 약호가 읽히는가. 흑백에서도 선이 구분되는가
- [ ] 접속표 CSV 를 엑셀로 열어보라 — 한글이 깨지지 않는가

## B 코스 — 밀도와 규모 (15분)

작은 하네스에서는 안 드러나는 문제들.

- [ ] **배선 20가닥 이상** 만들기 → 레인이 실제로 안 겹치는가,
      도면이 세로로 과하게 벌어지지 않는가
- [ ] 24핀 이상 커넥터(RJ45 8P, SMH250-10P)로 터미널 일괄 지정 →
      핀 패드 격자가 440px 안에서 읽히는가
- [ ] 스텁 라벨이 서로 겹쳐서 못 읽는 구간이 생기는가
- [ ] 커넥터 8개 이상 배치 → 도면이 여전히 읽히는가

## C 코스 — 조작감 (10분)

- [ ] **스페이스 + 드래그**로 화면 이동
- [ ] **두 손가락 스크롤**로 화면 이동 (트랙패드)
- [ ] **⌘ + 스크롤**로 확대·축소
- [ ] 빈 곳 드래그 → 점선 박스로 다중 선택
- [ ] Shift + 클릭으로 배선 여러 개 선택 → 속성 탭에 `MULTI` 배지,
      값이 다른 항목은 `여러 값` 으로 뜨는가
- [ ] 다중 선택 후 색 일괄 변경 → 전부 적용되는가
- [ ] **ESC** → 다중 → 단일 → 없음 순으로 한 단계씩 풀리는가
- [ ] 배선 여러 개 삭제 → 검은 토스트가 뜨고 **⌘Z 한 번에 전부 되돌아오는가**

> 팬 조작이 불편하면 알려달라. 박스 선택과 좌클릭 팬은 React Flow 에서
> 짝으로만 동작해서 하나를 고르면 다른 하나를 잃는다. 어느 쪽이 나은지는
> 실제로 써봐야 안다.

## D 코스 — 물리 뷰 ⚠️ 미검증 (10분)

배선이 있어야 활성화된다.

- [ ] `물리 뷰` 전환 → 구간이 다발로 그려지는가
- [ ] **구간 나눔이 실제 제작 형상과 맞는가** (이게 핵심 — 자동 산출이라 틀릴 수 있다)
- [ ] 분기점 마커: 스플라이스는 채운 마름모, 단순 분기는 빈 마름모
- [ ] 다발 굵기가 본수를 반영하는가
- [ ] 구간표 ↔ 도면 hover 동기
- [ ] 치수·자재 수량이 맞는가

## E 코스 — 세트 (10분)

- [ ] `+ 하네스` 로 두 번째 하네스 추가
- [ ] 세트 개요 → 하네스 카드의 **미니 스케마틱이 실제 도면을 닮았는가**
- [ ] 세트당 수량·주문 세트 수 변경 → 총수량이 즉시 따라오는가
- [ ] `발주 전 확인` 항목 클릭 → 해당 하네스·요소로 이동하는가
- [ ] 파트 탭 `하네스 단위` → **발주 문구를 복사해 실제로 보낼 만한가**
- [ ] `내보내기 설정…` → 범위를 세트 전체로 → 나올 파일 목록이 3배로 늘어나는가
- [ ] 세트 전체 PDF → 하네스마다 3면이 이어 붙는가

---

## F 코스 — 데이터 (10분)

- [ ] `JSON 저장` → `새 문서` → `JSON 불러오기` → **작업이 그대로 돌아오는가**
- [ ] 저장한 JSON 을 다른 브라우저/PC 에서 열기 → 도면이 재현되는가
      (부품 스냅샷이 함께 저장되므로 되어야 한다)
- [ ] 핀맵 에디터로 실제 쓰는 하우징 하나 정의 → 캔버스에 놓았을 때
      **정의한 형상 그대로 나오는가**
- [ ] 라이브러리 `내보내기` → JSON 받기 → `가져오기` 로 되돌리기
- [ ] **실제 엑셀 부품표를 CSV 로 저장해 가져오기** ⚠️ 미검증
      (헤더: `이름,분류,제조사,MPN,피치,열,행,핀수,신호,색,비고`)
      잘못된 행이 있을 때 그 행만 건너뛰고 사유가 뜨는가
- [ ] 새로고침 → 자동저장으로 작업이 남아 있는가

## 기록 양식

막히는 지점을 이 형식으로 남겨두면 바로 고칠 수 있다.

```
[화면] 물리 뷰
[무엇을 했나] 배선 12본짜리 하네스에서 물리 뷰로 전환
[기대] 구간이 4개로 나뉠 것
[실제] 구간이 7개로 쪼개짐, S3 과 S5 가 같은 경로인데 따로 잡힘
[심각도] 도면을 못 씀 / 불편함 / 사소함
```

**심각도 판단 기준**
- **도면을 못 씀** — 이게 있으면 현장에 낼 수 없다. 최우선
- **불편함** — 우회할 수 있지만 매번 거슬린다
- **사소함** — 눈에 띄지만 일에는 지장 없다

## 이미 알고 있는 미완성 (버그로 적지 않아도 됨)

- 보호재(슬리브·테이프)는 데이터 모델이 없어 물리 뷰 구간표에 `미지정` 으로 비어 있다
- 전장(全長)은 구간 데이터가 없어 근사치다 (최장 배선 기준)
- 외경은 `√본수 × 심선 외경` 추정값이다
- 레인은 자동 배정만 있고 손으로 옮길 수 없다
- 하네스 **요소 단위** 복제·이동이 없다 (하네스 통째 복제만 있음)
- 1280px 미만 화면은 대응하지 않았다
