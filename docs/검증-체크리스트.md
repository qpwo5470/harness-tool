## A 코스 — 실제 하네스 하나를 끝까지 (40~50분)

**실제로 만들 하네스 하나를 골라라.** 샘플을 만지지 말고 새로 만들어야
빈 상태부터 PDF 까지 전 경로가 드러난다.

### A-1. 시작

| 할 일 | 정상이면 이렇게 보인다 |
|---|---|
| 상단바 `새 문서` | 캔버스가 비고 온보딩 카드가 뜬다. **온보딩 위에서도 드롭이 통과해야 한다** |
| 상단바 문서명 칸에 이름 입력 | 도면 **우하단 제목블록** 왼쪽에 그 이름이 그대로 |
| 상단바 `도번` 칸에 값 입력 | 제목블록 첫 줄 오른쪽에 나온다 (비어 있으면 `—`) |
| 상단바 `Rev` 칸에 `A` 입력 | 제목블록 둘째 줄 오른쪽에 `Rev.A` |
| 상단바 `물리 뷰` 버튼 | 배선이 없으면 **비활성**이고 "배선이 있어야 제조 도면이 나옵니다" 툴팁 |

### A-2. 커넥터 배치

| 할 일 | 정상이면 이렇게 보인다 |
|---|---|
| 좌측 라이브러리 검색칸(`이름·MPN·신호 검색`)에 `SMH` 입력 | 연호 하우징들이 걸린다. 암/수/보드 배지가 붙는다(미지정은 안 붙는다) |
| 부품을 **캔버스로 끌어다 놓기** | 드래그 중 캔버스에 점선 테두리. 놓으면 **커서가 부품 가운데**에 오도록 놓인다 |
| 같은 부품을 클릭으로도 배치 | 클릭 배치도 여전히 된다(기본 위치) |
| `+ 장치 블록` 을 끌어다 놓기 | 장치 블록이 생긴다 |
| 압착단자(YST025 등)를 끌어 보기 | **드래그가 안 되는 게 맞다** (캔버스에 놓지 않는다). 시리즈 목록 맨 아래에 흐리게 있다 |
| 라이브러리 머리글을 위에서 아래로 훑기 | 계열 4칸(압착/규격 I/O/범용/구 항목) → 시리즈가 전부 `제조사 · 시리즈 · 피치` 꼴. 형식이 다른 칸이 하나라도 있으면 분류가 다시 섞인 것이다 |
| SMH250 을 찾아 하우징·웨이퍼·압착단자가 다 있는지 보기 | 한 칸(`연호전자 · SMH250 · SMP250 · 2.50mm`) 안에 셋이 함께 있어야 한다 — 발주는 셋을 다 골라야 끝난다 |
| 검색창에 `자판기` 입력 | MDB VMC/주변기기가 나온다(부품 이름에 그 말이 없는데도 — 시리즈 태그로 잡힌다) |
| 아무 행이나 골라 기호를 보기 | 빈 원 = 암 · 찬 원/네모 = 수/보드 · 압착 날개 = 단자 · Y자 = 스플라이스. 옆 고정 칸의 글자(암/수/보드)와 **반드시 일치**해야 한다 |
| 구 항목 칸에서 `Molex Mini-Fit Jr 4P` 보기 | 점선 `?` — 성별 미확인이라는 뜻이다. 조용히 비어 있으면 안 된다 |
| 필터 `보드측` · `수` 를 눌러 보기 | 시리즈 칸은 그대로 두고 행만 걸러진다. `해제` 로 253종이 전부 돌아온다 |
| 커넥터를 4~5개 **한 줄로** 늘어놓기 | (A-3 에서 관통 회피를 볼 준비) |

### A-3. 결선 — 가장 중요

| 할 일 | 정상이면 이렇게 보인다 |
|---|---|
| 핀에서 핀으로 드래그 | 배선이 생긴다 |
| 선이 어디서 나오는지 본다 | **정확히 그 핀 패드에서**, 변에 수직으로 곧게 나온 뒤에 꺾인다. 도형 한가운데나 옆구리에서 나오면 안 된다 |
| **1행 10P 같은 커넥터를 0°/180° 로 두고** 여러 핀에서 결선 | 핀이 **나가는 변을 따라 세로로 줄지어** 서고 배선 간격이 눈에 띄게 벌어진다(30px). 한 점에서 부챗살처럼 나오면 회귀다 |
| 방향을 0/90/180/270° 로 바꿔가며 결선 | 매번 맞는 변에서 나온다. **좌상단 등록 마크(1번 핀)는 언제나 좌상단**에 남는다 |
| 커넥터 한 줄 배치의 **양 끝**을 잇기 | 배선이 가운데 커넥터들을 **관통하지 않고** 위나 아래로 돌아간다. 관통하면 그 구간만 선이 사라져 보인다 |
| 이름표가 긴 커넥터(장치 이름을 길게) 옆으로 배선 통과 | 배선이 **이름표 흰 배경 뒤로 숨지 않는다** |
| 스플라이스에 3가닥 이상 물리기 | 접속표 NET 열에서 하나로 이어진다 |
| 규격 커넥터(RJ45 T568B)에 결선 | 규격 색이 자동 제안된다 |

### A-4. 값 채우기

| 할 일 | 정상이면 이렇게 보인다 |
|---|---|
| 배선 클릭 → 속성 탭 `색` | 규격 12색 칩. 고르면 도면 선 색이 즉시 바뀐다 |
| 규격 외 색을 **직접 입력** | 알 수 없는 이름은 회색으로 폴백(검정 아님) |
| `규격` 에서 게이지·길이 입력 | AWG ↔ mm² 전환 |
| **커넥터 클릭 → `터미널`** — 핀 패드 격자에서 여러 핀 골라 일괄 지정 | 핀이 24개여도 컨트롤은 2개. 토스트가 뜬다 |
| 장치 클릭 → `단자` 추가·이름 변경 | 이미 배선된 단자는 삭제가 막힌다. **한글 단자명("전원")이 블록 밖으로 안 나간다** |

### A-5. 케이블 (새로 생긴 경로)

케이블은 **1급 선택 대상이 아니다.** 반드시 심선(배선)을 먼저 고른다.

| 할 일 | 정상이면 이렇게 보인다 |
|---|---|
| 배선 클릭 → 속성 탭 `케이블 소속` → `+ 새 케이블` | 케이블이 생기고 이 배선이 거기 들어간다. **⌘Z 한 번**에 둘 다 되돌아간다(두 번이 아니다) |
| `+ 새 케이블` 을 빠르게 연타 | id 가 겹치지 않는다(버튼이 하나로 합쳐지지 않는다) |
| `케이블 길이` 에 300 입력 후 Enter | 배선의 길이 칸을 비워 둬도 접속표·물리 뷰·자재표가 전부 300mm 로 읽는다 |
| 케이블 길이를 **비우고** 확정 | 값이 지워진다(0 이 들어가지 않는다) |
| 심선에 개별 길이 720 입력 | 속성 문구가 "이 심선만 따로 재단 · 발주는 케이블로" 로 바뀐다. **파트리스트에서 전선 720 + 케이블 300 으로 이중 계상되면 안 된다** |
| 다른 배선도 같은 케이블에 넣고 코어 수를 낮춰 보기 | 검증에 `코어 수 부족` error. 반대면 `예비심 N심` info |
| `케이블 삭제` | 케이블만 사라지고 **심선(배선)은 도면에 남는다**. 토스트가 "심선 N본은 단선으로 남았습니다" |

### A-6. 확인

| 할 일 | 정상이면 이렇게 보인다 |
|---|---|
| 접속표 탭 — 행에 마우스 올리기 | 도면에서 그 배선이 굵어지고 나머지는 흐려진다 |
| 도면 배선에 마우스 올리기 | 커서 옆 상세 카드 + 접속표 행 강조. **선을 벗어나면 카드가 즉시 사라진다** |
| 도면 배선을 클릭해 고정 | 상세 카드는 **뜨지 않는다**(값은 속성 탭에 있다). 선 뒤에 얇은 스틸 실선 |
| **검증 탭** | 지적이 error → warn → info 순. 각 항목에 **왜 문제인지** 한 문장 |
| 검증 항목 클릭 | 그 요소가 선택되고 속성 탭으로 넘어간다 |
| 파트 탭 | 수량이 실제 필요 수량과 맞는가. 길이가 일부만 있으면 **"(N본 기준)"** 이 붙는다 |

### A-7. 출력

| 할 일 | 정상이면 이렇게 보인다 |
|---|---|
| 상단바 `PDF 도면` | 파일 하나가 받아진다 |
| **PDF 를 열어라** | 3면(배선도·접속표·파트리스트). 표가 길면 더 늘어난다 |
| 배선도 면을 화면과 **나란히 놓고 비교** | **레인 분리가 화면과 같아야 한다.** 스무 가닥이 한 줄에 포개지면 회귀다 |
| 같은 배선의 우회 경로 확인 | 화면에서 박스 아래로 돌아가는 배선은 PDF 에서도 아래로 돌아간다 |
| 한글 | 안 깨진다(Latin-1 밖 글자만 래스터). 품번·AWG·핀번호는 벡터라 선명하고 검색된다 |
| 제목블록 | 도번·Rev·SCALE 이 나온다 |
| **인쇄해 보라** ⚠️ 아직 아무도 안 해 봤다 | 핀 번호·색 약호가 읽히는가. 흑백에서 선이 구분되는가 |
| 접속표 CSV 를 엑셀로 열기 | 한글이 안 깨진다. 헤더가 `wire,net,from,to,color,gauge,length_mm` |

## B 코스 — 밀도와 규모 (15분)

작은 하네스에서는 안 드러나는 문제들.

- [ ] **배선 20가닥 이상** — 가로 주행 구간이 서로 겹치지 않는가.
      도면이 세로로 과하게 벌어지지 않는가
- [ ] 같은 커넥터 한 변에서 여러 가닥이 나갈 때 — **세로 간선이 x 로 벌어지는가**
      (laneX). 한 줄에 포개지면 회귀
- [ ] 20본에서 스텁 라벨(색 약호 + 신호명) 좌표가 겹치는 쌍이 있는가.
      라벨은 **도착 패드 직전 구간**에 있어야 한다(경로 한가운데가 아니라)
- [ ] 커넥터 8개 이상, 그중 여럿을 **한 줄로** — 관통이 0인가.
      관통이 있으면 검증 탭에 `배선이 부품을 지남` warn 이 뜬다.
      **떠야 정상이다** — 라우터가 못 비켰다는 사실을 툴이 알고 있다는 뜻
- [ ] 부품 두 개를 **일부러 겹쳐** 놓기 → 관통이 생기고 warn 이 뜨는가
      (자동으로 옮겨 주지는 않는다)
- [ ] 24핀 이상 커넥터(RJ45 8P, SMH250-10P, USB-C 24P)로 터미널 일괄 지정 →
      핀 패드 격자가 읽히는가
- [ ] 200본 규모에서 편집이 체감상 끊기는가 (감사 측정 ~9ms/편집. 그보다 훨씬
      느리면 React Flow 렌더 쪽이고, 그건 아직 아무도 안 재 봤다)

## C 코스 — 조작감 (10분) · **바뀌었다**

| 손짓 | 정상이면 이렇게 된다 |
|---|---|
| 빈 곳에서 **좌클릭 드래그** | 화면이 이동한다 |
| **Alt(Option) + 드래그** | 점선 박스로 다중 선택 |
| **Shift + 클릭** (배선 위) | 집합에 더해진다. 다시 누르면 빠진다 |
| **⌘/Ctrl + 클릭** (배선 위) | 위와 같다. **선택이 통째로 풀리면 회귀다** |
| 두 손가락 스크롤 | 화면 이동 |
| 트랙패드 **핀치** | 확대·축소 |
| 좌하단 **± 버튼** | 확대·축소 |
| **⌘ + 스크롤** | **아무 일도 안 일어나는 게 맞다** — 뺐다 |
| 배선을 살짝 빗맞혀 수정키 누른 채 빈 곳 클릭 | 고르던 것이 **풀리지 않는다**("더하려던 손짓"으로 본다) |
| 다중 선택 상태 | 도면 좌측에 `N본 선택 · ESC 해제` 배지. 속성 탭에 `MULTI` 배지, 값이 다른 항목은 `여러 값` |
| 다중 선택 후 색 일괄 변경 | 전부 적용 |
| **ESC** | **한 단계씩** — 다중 → 단일 → 없음. 한 번에 다 풀리면 회귀 |
| 배선 여러 개 삭제 | 검은 토스트 + **⌘Z 한 번**에 전부 되돌아온다 |
| 속성 탭 입력칸에서 ESC | 캔버스와 같은 규칙(한 단계). 모달이 떠 있으면 모달이 먼저 |

## D 코스 — 물리 뷰 (15분)

배선이 있어야 활성화된다.

- [ ] `물리 뷰` 전환 → 구간이 다발로 그려지는가
- [ ] **구간 나눔이 실제 제작 형상과 맞는가** ⚠️ 자동 산출이라 틀릴 수 있다.
      이게 이 코스의 핵심
- [ ] 분기점 마커: 스플라이스는 **채운** 마름모, 단순 분기는 **빈** 마름모
- [ ] 다발 굵기가 본수를 반영하는가
- [ ] **치수선(티크 달린)이 그려진 구간과 `—` 인 구간을 구분해 보라.**
      치수선은 "그 구간이 곧 전 경로인 배선"이 있을 때만 그려진다.
      경유 배선밖에 없는 구간에 숫자가 찍혀 있으면 회귀다
- [ ] J1-SP1 100mm 2본 · SP1-J2 150mm 2본 · J1-J2 직결 900mm 를 만들어 보라 →
      **두 구간이 900 으로 찍히면 회귀다** (100 / 150 이 맞다)
- [ ] 500mm + 500mm 를 스플라이스로 이어 보라 → **전장이 1,000mm** 로 나오는가
      (500 이면 회귀). 확정 못 할 때는 `최장 배선` 이라고 이름 그대로 적어야 한다
- [ ] **구간표의 길이 칸에 실측값을 입력** → 도면에 치수선이 생기고 표에
      `입력값` 배지가 붙는다. 비우고 확정하면 유도값(없으면 미상)으로 돌아간다
- [ ] 유도값이 있는 구간에 **다른** 값을 입력 → 검증 탭에
      `구간 길이 불일치` warn. **자동으로 고쳐지지 않는 게 맞다**
- [ ] 구간 길이를 넣은 뒤 **배선을 하나 추가**해 구간이 갈라지게 하라 →
      `쓰이지 않는 구간 길이 N건` info. 넣어 둔 값이 **엉뚱한 옆 구간에 붙으면 회귀다**
- [ ] 파트리스트를 확인 → **구간 길이가 자재표에 더해지면 안 된다**
- [ ] 구간표 ↔ 도면 hover 동기
- [ ] 외경 옆에 "추정" 표시, 보호재는 `미지정`

## E 코스 — 세트 (15분)

- [ ] `+ 하네스` 로 두 번째 하네스 추가
- [ ] 세트 개요 → 하네스 카드의 **미니 스케마틱이 실제 도면과 같은 모양인가**
      (1행 10P 커넥터를 넣어 보라 — 캔버스에서 세로로 긴 것은 카드에서도 세로로 길어야 한다)
- [ ] 길이를 아직 안 넣은 하네스 카드 → **`0mm` 가 아니라 `길이 미입력`**.
      일부만 알면 `1,600mm (2본 기준)`
- [ ] 세트당 수량·주문 세트 수 변경 → 총수량이 즉시 따라온다
- [ ] **세트 수량을 바꾼 뒤 ⌘Z** → 수량이 되돌아온다.
      **그 앞의 도면 편집이 지워지면 회귀다**
- [ ] 세트 이름을 여러 글자 타이핑 후 ⌘Z → 한 덩어리로 되돌아온다(글자마다 아님)
- [ ] 세트 개요를 보는 중에 ⌘Z → **어느 하네스 도면이 되돌아갔는지 토스트로 알린다**
- [ ] `발주 전 확인` 항목 클릭 → 해당 하네스·요소로 이동
- [ ] 파트 탭 `하네스 단위` → **발주 문구를 복사해 실제로 보낼 만한가**
- [ ] 세트 개요의 `JSON 가져오기` → **세트가 통째로 갈아치워지지 않고 하네스가 추가**되는가
- [ ] 하네스 하나 삭제 → 남은 하네스 문자가 A, B, C 로 **다시 매겨지는가**(A, C 로 구멍 나면 회귀)

## F 코스 — 내보내기 (15분) · **크게 바뀌었다**

- [ ] `내보내기 ▾` → `내보내기 설정…`
- [ ] 범위를 **세트 전체**로 → 우측 `나올 파일` 목록이 하네스 수만큼 늘어난다
- [ ] 목록의 파일명 규칙 확인 — `[세트품번]_[문자]_[종류]_[Rev]`
- [ ] 내보내기 실행 → **파일이 2개 이상이면 ZIP 하나**로 받아진다.
      27개 중 1개만 떨어지면 회귀
- [ ] 진행 중 → 버튼이 잠기고 `7/27` 처럼 세어 보여 준다
- [ ] **ZIP 을 풀어라** — 파일 수가 미리보기 목록과 **정확히 같은가**.
      **한글 파일명이 안 깨지는가**. 이름에 `_RevA` 가 붙어 있는가
- [ ] `하네스 BOM CSV` 를 체크 → **실제로 파일이 나오는가**(예전엔 안 나왔다)
- [ ] **전선 여유율 5%** → 파트리스트 CSV 에 `drawing_length_mm` `order_margin_pct`
      `order_length_mm` 세 열. 800 / 5 / 840
- [ ] 같은 설정에서 **접속표 CSV 와 PDF 는 800 그대로**여야 한다
      (여유율이 붙으면 현장이 도면보다 긴 전선을 자른다)
- [ ] 여유율 **0%** → 열이 사라지지 않고 `order_margin_pct = 0` 으로 남는다
- [ ] 여유율 `직접` 에 `-5` 나 `999` 입력 → 0 ~ 100 으로 눌러 담긴다
- [ ] **치수 단위 inch** → 열 이름이 `length_in` 으로 **바뀐다**(값만 바뀌면 회귀).
      800mm → 31.496
- [ ] 접속표 **CSV 열 선택** — 칩을 껐다 켜면 실제 CSV 열이 그대로 따라온다.
      순서도 고른 순서대로
- [ ] 열을 **하나도** 안 고르면 → 버튼이 잠기고 이유를 말한다(빈 CSV 가 안 나간다)
- [ ] 용지 A3 ↔ A4 → PDF 크기가 바뀐다
- [ ] 문서 JSON 을 함께 내보내기 → **표시 단위를 inch 로 둬도 JSON 안은 mm 원본**

## G 코스 — 데이터 왕복 (15분)

- [ ] `JSON 저장 (세트 전체)` → `새 문서` → `JSON 불러오기` → **작업이 그대로 돌아오는가**
- [ ] **`새 문서` 를 누른 뒤 작업하고 저장** → 그 작업이 파일에 들어 있는가
      (예전엔 통째로 빠졌다)
- [ ] 저장한 JSON 을 다른 브라우저/PC 에서 열기 → 도면이 재현되는가
      (부품 스냅샷이 함께 저장되므로 되어야 한다)
- [ ] 새로고침 → 자동저장으로 작업이 남아 있는가
- [ ] **일부러 망가뜨린 파일 열기** (아래 넷을 각각) → **조용히 무시되지 않고
      이유가 뜨는가**
  - JSON 이 아닌 파일 → `JSON 파일이 아닙니다`
  - `{"schemaVersion": 3, ...}` → **거부**하고 "툴을 최신으로 올린 뒤 열어 주세요"
  - `connectors` 키를 지운 파일 → 화면이 백지가 되지 않고 경고와 함께 열린다
  - 색이 없는 배선이 섞인 파일 → 그 배선만 빠지고 **몇 본을 왜 뺐는지** 알린다
- [ ] 없는 케이블을 가리키는 배선이 든 파일 → 불러올 때 알리고 검증이 짚는다.
      **자동으로 `cableId` 를 지우면 안 된다**
- [ ] 없는 부품을 가리키는 구간 길이 키가 든 파일 → 건수와 이유를 알리고 버린다
- [ ] 핀맵 에디터로 **이미 캔버스에 놓인** 하우징을 고치기 →
      **도면이 실제로 바뀌는가**(예전엔 안 바뀌었다)
- [ ] 핀 수를 6P → 2P 로 줄이기 → 배선이 물린 핀은 **지워지지 않고**
      하우징 박스 **아래 줄에** 남는다(박스 밖 허공에 뜨면 회귀). 검증이 `핀 수 초과` 로 짚는다
- [ ] 라이브러리 `내보내기` → JSON 받기 → `가져오기` 로 되돌리기
- [ ] **실제 엑셀 부품표를 CSV 로 저장해 가져오기** ⚠️ 미검증
      (헤더: `이름,분류,제조사,MPN,피치,열,행,핀수,신호,색,비고,성별` — 순서 무관, 영문 헤더도 됨)
  - [ ] 따옴표를 일부러 안 닫은 행을 넣어 보라 → **나머지 행을 통째로 잃지 않고** 알리는가
  - [ ] 중복 MPN·핀 수 미상·쉼표가 하나 더 있는 행 → 몇 행이 왜 그런지 알리는가
  - [ ] 안내 문구가 **사실인가** (보정만 했는데 "건너뛴 행 3건" 이라 적으면 거짓말이다)

## 기록 양식

막히는 지점을 이 형식으로 남겨두면 바로 고칠 수 있다.

```
[화면] 물리 뷰
[무엇을 했나] 배선 12본짜리 하네스에서 물리 뷰로 전환
[기대] 구간이 4개로 나뉠 것
[실제] 구간이 7개로 쪼개짐, S3 과 S5 가 같은 경로인데 따로 잡힘
[심각도] 도면을 못 씀 / 불편함 / 사소함
```

**심각도 판단 기준**
- **도면을 못 씀** — 이게 있으면 현장에 낼 수 없다. 최우선
- **불편함** — 우회할 수 있지만 매번 거슬린다
- **사소함** — 눈에 띄지만 일에는 지장 없다

> **화면과 산출물이 어긋나는 것은 무조건 "도면을 못 씀" 이다.**
> 접속표는 맞는데 PDF 만 틀린 경우, 화면은 맞는데 카드만 옛 모양인 경우 —
> 이 부류가 지금까지 난 사고의 절반이다.

## 이미 알고 있는 미완성 (버그로 적지 않아도 됨)

자세한 내용은 `인수인계.md` §8.

- **자켓이 안 그려지는 배치가 있다** — 심선이 멀리 벌어지거나 사이를 남의 배선이
  지나면 그 구간엔 자켓이 없다. 샘플 문서의 2심 케이블이 그렇다.
  케이블 카드가 "지금 배치에서는 자켓이 그려지지 않습니다" 로 밝히면 정상
- **파트 탭에서 케이블 행을 눌러 고를 수 없다** — 캔버스 자켓과 검증 탭이 통로다
- **물리 뷰가 PDF 에 없다** — 구간·전장은 화면에만 있다
- **라우터가 병적 배치(겹쳐 놓은 부품 등)에서는 관통한다** — 검증이 알리지만
  자동으로 옮겨 주지는 않는다
- **레인 수동 조정이 없다** — 자동 배정만
- **보호재(슬리브·테이프)는 데이터 모델이 없다** — 구간표에 `미지정`
- **외경은 `√본수 × 심선 외경` 추정값이다**
- **글자 폭은 어림이다**(`estimateTextWidth`) — 폰트를 바꾸면 라벨이 상자 밖으로
  나갈 수 있다
- **하네스 요소 단위 복제·이동이 없다** (하네스 통째 복제만 있음)
- **커넥터 암수 짝 관리가 없다** (`gender` 배지는 있지만 짝 관계는 데이터에 없다)
- **1280px 미만 화면은 대응하지 않았다**
- **React Flow 렌더 비용을 재 본 적이 없다** — 순수 함수 구간만 쟀다
